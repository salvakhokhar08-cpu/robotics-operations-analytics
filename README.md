# Robotics Operations & Maintenance Analytics

## Project Overview

This project analyzes robotics operations and maintenance data to identify patterns in robot performance, downtime, failures, maintenance costs, and energy consumption.

## Objectives

- Analyze robot performance
- Identify downtime and failure patterns
- Evaluate maintenance costs
- Compare preventive and corrective maintenance
- Analyze energy consumption
- Identify opportunities for operational improvement

## Tools

- Excel
- Python
- Power BI
- GitHub

## Key Metrics

- Operating Hours
- Downtime Hours
- Failure Count
- Maintenance Cost
- Energy Consumption
- Performance Score

## Project Purpose

This project demonstrates my Business Analytics skills and my interest in applying data-driven analysis to technology, robotics, and operational efficiency.
